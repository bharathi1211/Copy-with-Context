# Copy With Context

A simple Chrome extension that lets you copy selected text along with its source URL and page title in Markdown format.

## Features

- Copy selected text as a Markdown quote.
- Automatically include the webpage title and URL.
- Preview the formatted text before copying.
- Save a history of copied quotes.
- Copy previous quotes again whenever needed.
- Clear your copy history.

## Installation

1. Download this repository by clicking **Code → Download ZIP**.
2. Extract the downloaded ZIP file.
3. Open Google Chrome and visit `chrome://extensions`.
4. Enable **Developer mode**.
5. Click **Load unpacked**.
6. Select the extracted folder containing `manifest.json`.

The extension should now appear in your Chrome extensions list.

## Usage

1. Open a webpage.
2. Select the text you want to save.
3. Click the Copy With Context extension icon.
4. Preview the quote and click the copy button.
5. Access previously copied quotes from the history section.
